# Phase 2 – Software Test Plan (STP)

This folder contains the Software Test Plan (STP) documentation for Team 13's Web-Based ML Model Evaluator project. The STP establishes the approach for verifying and validating the application against its specified requirements and expected functionality.

The document outlines the testing scope, objectives, test strategy, and planned activities for assessing the system's behavior and reliability. It serves as a reference for organizing test cases, identifying potential defects, and checking that the implemented features meet the project's requirements as development progresses.
