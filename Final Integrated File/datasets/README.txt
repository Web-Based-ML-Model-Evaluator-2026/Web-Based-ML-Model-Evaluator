ModelLab Demo Dataset Pack
=========================

Five synthetic datasets created for demonstrating upload, preprocessing, model training,
evaluation, comparison, and report generation. All records are synthetic; no real personal
or medical information is included.

Files and recommended targets:
1. 01_customer_churn_800x27.csv — 800 rows, 27 columns; classification target: churn
2. 02_credit_default_750x30.csv — 750 rows, 30 columns; classification target: default
3. 03_hospital_readmission_900x27.csv — 900 rows, 27 columns; classification target: readmission_30d
4. 04_retail_sales_1000x27.csv — 1,000 rows, 27 columns; regression target: sales_amount
5. 05_employee_attrition_650x28.csv — 650 rows, 28 columns; classification target: attrition

Demo notes:
- Select the listed target column in ModelLab.
- These are synthetic, intentionally noisy datasets designed to yield varied metrics.
- Results can vary by model, preprocessing choices, and random train/test split.
- Do not present these synthetic results as validated real-world findings.
