# Run the Categorical Encoding Demo

1. Extract the ZIP.
2. Open `CategoricalEncoding_Demo` in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown in the terminal, usually `http://localhost:5173/`.
7. Test One-Hot Encoding and Label Encoding. Optionally load a CSV with headers.
8. Stop the server with `Ctrl+C`.

This is a separate test app. Copy only `Task_3.2_Parinitha_Categorical_Encoding` into the team's Sprint 3 folder.
