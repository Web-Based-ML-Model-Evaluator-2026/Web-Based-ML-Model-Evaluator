## About the Project

The **Web-Based ML Model Evaluator** is a web-based application designed to provide a simple and organized platform for evaluating supervised Machine Learning models using tabular datasets. It brings the major stages of dataset handling, model selection, training, testing, and performance evaluation into a single web interface.

The system will allow users to upload and validate datasets, select the appropriate ML task and model, and perform the required preprocessing and model-training operations. After training, the model will be evaluated using suitable performance metrics, allowing users to understand how well the selected model performs on the given dataset.

The application will also provide a structured way to view and compare evaluation results. Important outputs such as model performance metrics and visual results will be presented through the web interface, making it easier for users to analyze the behaviour of different models and select a suitable model based on the evaluation results.

The project will be developed as a modular web application following Software Engineering principles. The system will contain separate components for user interaction, dataset management, machine-learning processing, evaluation, and result presentation. Development and collaboration will be managed using GitHub, while the system will be tested progressively to ensure that the implemented functionality meets the requirements defined in the SRS.
