# Phase 3 – Software Architecture Document (SAD)

This folder contains the Software Architecture Document (SAD) for Team 13's Web-Based ML Model Evaluator project. The document describes the high-level architecture of the application and explains how its major components are organized to support the project's objectives.

The SAD serves as a technical reference for understanding the system's structure, component responsibilities, and interactions. It helps guide implementation and integration by providing an architectural foundation for the frontend, backend, data handling, and other system components described in the document.
