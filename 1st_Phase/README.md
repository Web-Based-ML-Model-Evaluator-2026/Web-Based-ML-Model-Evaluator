# Phase 1 – Project Documentation

This folder contains the initial documentation prepared for Phase 1 of the **Web-Based ML Model Evaluator** project by Team 13. It includes the project title document, which establishes the official project name, and the Software Requirements Specification (SRS) document, which serves as the foundation for documenting the system's requirements and expected functionality.

The SRS documentation is intended to describe the purpose and scope of the application, its functional and non-functional requirements, and the expected interactions between users and the system. The project aims to provide a web-based platform for working with machine learning datasets and evaluating models. These documents provide the initial reference for understanding the project and guiding subsequent design, development, and testing activities.

## Documents Included

- `Team-13_Title-(Web_Based_ML_Model_Evaluator).pdf` – Project title document for Team 13.
- `SRS_Template for SE _partial_updated.pdf` – Software Requirements Specification documentation for the project.
